

# Дополнение: текстура мусорки + готовый промпт для Antigravity

## Что не так

В прошлом ответе я выдал 5 текстур (горящая мусорка, огонь, дым, канистра, спички), но:
1. **Не приложил исходную (негорящую) мусорку** — она нужна как «база» для свапа текстур (`dumpster` → `dumpster_burning`). В проекте уже есть `public/game/dumpster.png`, но она нарисована в старом стиле и может не стыковаться визуально с новой `dumpster_burning.png` (разные пропорции/палитра → при поджиге будет «прыжок» спрайта).
2. **Не оформил промпт** для Antigravity отдельным копируемым блоком — был размазан по сообщению.

## План

### A. Перерисовать `public/game/dumpster.png`

Сгенерировать новую базовую мусорку **в той же пиксель-арт стилистике, пропорциях и размере**, что и `dumpster_burning.png`, чтобы при свапе текстур не было визуального скачка:
- Тот же ракурс (3/4, чуть сбоку), тот же силуэт, те же габариты канваса.
- Зелёный металлический бак с крышкой, тёмный контур, лёгкая ржавчина/потёртости — но **без огня, дыма, тления**.
- Та же палитра базы (зелёный корпус, серая крышка, чёрный контур), что и у горящей версии — чтобы пара читалась как «состояние выкл/вкл».

Файл перезапишет существующий `public/game/dumpster.png` (он уже подгружается в `BootScene` как `this.load.image("dumpster", ...)` — никаких правок в коде загрузки не нужно).

### B. Готовый промпт для Antigravity

Оформить отдельным markdown-блоком, который пользователь скопирует и вставит в Antigravity. Содержание:

1. **Контекст**: краткое описание игры (SNAF, Phaser 3, GameScene), куда добавить механику.
2. **Ассеты**: список из 6 файлов (`dumpster.png`, `dumpster_burning.png`, `flame_fx.png`, `smoke_fx.png`, `jerrycan.png`, `match_icon.png`) с указанием папки `public/game/` и тем, что они уже загружены / какие надо добавить в `BootScene.preload()`.
3. **Состояние**: расширить `registry.game` полями `inv: { fuel: boolean, matches: number }`, у каждой мусорки — `burning: boolean`, `burnedOut: boolean`, `burnTimer: number`.
4. **Пикапы**: спавнить `jerrycan` и `match_icon` как статичные спрайты на уровне; при overlap с игроком — увеличивать инвентарь, спрайт удалять, тостер в HUD.
5. **Поджиг**: клавиша `F` рядом с мусоркой при `inv.fuel && inv.matches > 0` → списать ресурсы, `dumpster.setTexture("dumpster_burning")`, создать два `ParticleEmitter` (`flame_fx` снизу вверх, `smoke_fx` выше с альфа-фейдом), запустить `burnTimer = 8000ms`.
6. **AI копов**: в `updateCop` проверять расстояние до любой `burning` мусорки; если `< SCARE_RADIUS (350px)` — переключать в state `flee`, скорость в сторону **от** огня, игнорировать игрока, сбрасывать `alertLevel`. По выходу из радиуса (или после `burnedOut`) — возврат в `patrol`.
7. **Догорание**: по `burnTimer <= 0` → `burnedOut = true`, остановить эмиттеры, тинт `0x555555`, мусорка перестаёт пугать копов и не даёт `enterDumpster`.
8. **HUD (`UIScene`)**: иконки канистры/спичек с числом, иконка «🔥 поджечь [F]» когда условия выполнены.
9. **README**: добавить раздел «Механика поджога», новые константы (`SCARE_RADIUS`, `BURN_DURATION`, `FUEL_PICKUPS`, `MATCH_PICKUPS`), клавишу F в таблицу управления.
10. **Тюнинг**: рекомендуемые значения (радиус, длительность, число пикапов на уровень, cost: 1 канистра + 1 спичка на поджиг).

Промпт будет на русском, ~60-100 строк, готовый к вставке.

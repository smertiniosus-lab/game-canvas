
# 2D Run & Gun платформер (Cuphead-style) — MVP

Создадим веб-игру в стиле Cuphead: один уровень-демо со скроллингом, стрельбой, врагами и мини-боссом в конце. Движок — **Phaser 3** (интегрирован в React-страницу).

## Что войдёт в демо

### Игровой процесс
- **Управление**: ← → для движения, Space/↑ для прыжка (с двойным прыжком), X — стрельба, Z — дэш/уворот
- **Главный герой**: бежит, прыгает, стреляет в 8 направлениях, имеет 3 HP и анимацию урона
- **Скроллинг камеры**: плавно следует за игроком по горизонтали (side-scroller), с параллакс-фоном из 3 слоёв для глубины
- **Оружие**: непрерывная стрельба «пульками», отдача-эффект
- **Враги** (2 типа): простой шагающий моб + летающий стреляющий моб; оба дают урон при контакте
- **Мини-босс** в конце уровня: 2 простых паттерна атаки (прыжок + волна снарядов), полоска HP сверху
- **Коллектиблы**: монетки/звёзды по уровню для счёта
- **Победа/поражение**: экран Game Over с рестартом, экран Victory после убийства босса

### Визуальный стиль (Cuphead-вдохновение)
- Мультяшная палитра: тёплые кремовые тона, насыщенные акценты (красный, бирюзовый, горчичный)
- Эффект «старой плёнки»: лёгкая виньетка и зерно поверх канваса
- Рамка-«мультик» вокруг игрового поля
- Ассеты сгенерируем через Lovable AI в едином ретро-мультяшном стиле (герой, 2 врага, босс, тайлы платформ, фоновые слои)
- Заставка в стиле title card («Round 1 — Forest Frenzy, FIGHT!»)

### UI
- HUD сверху: HP (сердечки), счёт, патроны (если решим лимитировать)
- Главное меню: PLAY / CONTROLS
- Пауза по Esc

## Техническая структура
- **Phaser 3** монтируется в React-компонент на странице `/` через `useEffect` + `phaser.Game` в `<div ref>`
- Сцены Phaser: `BootScene` (загрузка ассетов), `MenuScene`, `GameScene` (уровень), `UIScene` (HUD оверлей), `GameOverScene`
- Тайлмап уровня — простой массив (без редактора), физика Arcade
- Ассеты в `public/game/` (сгенерируем спрайты и фоны)

## Что НЕ войдёт в этот этап (можно добавить позже)
- Сохранения, прокачка, несколько уровней
- Звук и музыка (добавим отдельной итерацией, чтобы не раздувать первую версию)
- Мобильное touch-управление (только клавиатура для MVP)

После этой итерации покажу, как играется, и сможем добавлять боссов, уровни, звуки и эффекты пошагово.

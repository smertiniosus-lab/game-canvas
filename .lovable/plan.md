

# Финальная полировка ассетов + инструкция к проекту

Цель: подтянуть текстуры до того состояния, что задумывалось (грозный SNAF с красными элементами вместо аккуратного жёлтого), убрать визуальные несоответствия по остальным ассетам, и оставить читаемую инструкцию для передачи в Antigravity.

## Что не так с текущим тэгом

Сейчас при покраске стены поверх неё рисуется текст `SNAF`:
```ts
fontFamily: "'Impact', 'Arial Black', sans-serif",
color: "#ffd400",        // жёлтый
stroke: "#000000",       // чёрный контур
```
Это «аккуратная надпись», а нужен **граффити-тэг**: размашистый, агрессивный, с красными подтёками/акцентами, тенью краски, эффектом баллончика. Без этого финальный результат закраски выглядит блёкло.

## План фиксов

### A. Грозный граффити-тэг SNAF с красными элементами

В `spawnWall` и `updateTagging` (`src/game/scenes/GameScene.ts`) переделать вид тэга:

1. **Базовый текст SNAF**:
   - Цвет — красный `#e02828` (кроваво-красный, как баллончик с красной краской).
   - Контур — чёрный, толстый (`strokeThickness: 10`).
   - Шрифт — `'Impact', 'Arial Black'` (как сейчас), `fontStyle: 'italic'` для наклона/динамики.
   - Лёгкий tilt: `setAngle(-6)` — будто рисовали в спешке.
2. **Эффект краски**:
   - Внешняя тень-свечение красной краской: `setShadow(0, 0, '#ff2020', 16, true, true)`.
   - Дополнительный полупрозрачный слой текста под основным — смещённый на +3px вниз, цвет `#1a0000` (тёмная подложка-«мокрая краска»).
3. **Подтёки (drips)**: после `done = true` под каждой буквой нарисовать 1–2 коротких вертикальных красных прямоугольника (5×12-22px, alpha 0.85, цвет `#c01818`), имитирующих стекающую краску. Длина — рандомная.
4. **Брызги вокруг тэга**: 6–10 мелких красных точек (`add.circle` r=2–4, alpha 0.6–0.9) в радиусе 10-30px от букв.

В процессе закраски (пока буквы появляются по одной) — те же красные цвета, но без подтёков и брызг (они добавляются только в момент `done`).

### B. Аудит остальных ассетов

Проверка/корректировка отображения, без перегенерации:
- **Спрайт-fx баллончика** (`spray_fx`) — сейчас просто полупрозрачное облако, оставить, но изменить tint при отрисовке на `0xff3030` чтобы соответствовало красной краске тэга: `.setTint(0xff3030)` при создании fx в `updateTagging`.
- **Маркер «куда красить»** (жёлтая стрелка ▼ + амбер-glow) — оставить жёлтым, это UI-индикатор, не часть граффити.
- **Title card** «ЗАДАНИЕ НА НОЧЬ / ЗАКРАСИТЬ 5 СТЕН» — добавить ниже маленький превью SNAF в новом красном стиле для согласованности.
- **Game Over (победа)** — заголовок «РАЙОН РАЗМЕЧЕН» добавить красный акцент: подзаголовок «Улицы запомнят твой тег.» — уже есть, добавить под ним мини-SNAF в красном.

### C. Перегенерация текстуры `wall_tagged.png` (опциональная, но логичная)

Текстура `wall_tagged.png` сейчас в проекте лежит, но не используется (после прошлого фикса мы перестали `setTexture("wall_tagged")`). Два варианта:
- **Удалить** загрузку из `BootScene` и сам файл из `public/game/` — мёртвый ассет.
- **Перегенерировать** в новом стиле (грозный красный SNAF на гараже) — пригодится как фоновое полотно меню или для будущего «уже затэганной до нас» стены.

Выбираем: **удалить** загрузку из `BootScene` (строка `this.load.image("wall_tagged", ...)`), сам файл оставить в `public/game/` чтобы не править публичные ассеты — никакого визуального эффекта это не даст.
